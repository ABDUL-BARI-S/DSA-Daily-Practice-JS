# Problems Solved

## 1. Valid Anagram

Check whether two given strings are anagrams of each other by comparing their characters and their frequencies.

**Example:** `listen` and `silent` are valid anagrams.

**Note:** Anagrams contain the same characters with the same frequency, but the order of characters can be different.

# 2. Capitalize First Letter of Every Word

Write a program to capitalize the first letter of each word in a given string.

**Example:**

Input:
```text
hello world javascript
```

Output:
```text
Hello World Javascript
```

**Approach:**
- Traverse the string character by character.
- Capitalize the first character of the string.
- Whenever a space is found, capitalize the next character.
- Append the remaining characters as they are.
